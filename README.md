Este projeto implementa um CRUD de clientes em Spring Boot usando JPA com banco H2 em memória. Optei por não manter uma lista local em memória e trabalhar apenas com o repositório JPA,pois   uma única fonte de dados elimina divergências entre o que está na lista e o que está no banco, evita problemas de concorrência e garante persistência durante a execução da aplicação, além de deixar o código menor e mais direto.
Também não utilizei queries JPQL personalizadas; Entendi que o Spring Data já atendia o necessário, em especial a busca por nome com “contém” e sem distinção de maiúsculas/minúsculas via `findByNomeContainingIgnoreCase(String nome)`.
